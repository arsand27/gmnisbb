# Website DPC GMNI Seram Bagian Barat — prototipe awal

## Isi
- `index.html`: halaman publik responsif.
- `admin.html`: contoh tampilan dashboard pengelola.
- `styles.css`: desain modern minimalis premium.
- `script.js`: interaksi menu mobile.

## Menjalankan
Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.

## Penting: status prototipe
Dashboard admin saat ini hanya mockup visual. Belum ada autentikasi, database, unggah file, atau penyimpanan permanen. Jangan gunakan untuk mengelola data sungguhan sebelum backend dan kontrol akses disiapkan.

## Tahap berikutnya
1. Ganti logo dan identitas dengan aset resmi DPC.
2. Masukkan profil, struktur, komisariat, kontak, dan periode kepengurusan yang telah diverifikasi.
3. Hubungkan Supabase (database, storage, dan autentikasi berbasis peran).
4. Uji akses admin, keamanan unggahan, pencadangan, dan tampilan mobile.
5. Publikasikan melalui hosting dan domain resmi.
